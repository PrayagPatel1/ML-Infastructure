# Custom Machine Learning Infastructure

A small educational machine learning infastructure were you can train small neural
networks like MINST classifiers using custom made tensor, autograd, basic neural
network layers, SGD and Adam, dataloaders, checkpointing, training loop, vectorized operations, and a MINST demo using this infastructure.

I am going to be using Python 3.14.4, Numpy for memory storage, and Matplotlib for loss curves, debugging, and other visualizations.

The goal of this project is to create a neural network that can classify shapes as an example using this machine learning framework only. This would show that the framework
works as it is intended and will give the entire project some direction to follow.
