# MiniML - Custom Machine Learning Infastructure

MiniML is an educational machine learning framework with an end goal of constructing a basic binary classifier neural network.

## Features

As of now, matrix and vectors have been implemented along with basic operations associated with these mathematical objects. Currently, 0D tensors are being implemented as a struct called Value with basic arithmetic operations, visualizing the computation graph in the terminal, and the ability to do both forward pass and backward pass (backpropagation).

## Use of Artifical Intelligence

Currently AI is only being used to timeline this entire project and be able to help what core components needs to be implemented inorder to reach a point where we can implement a binary classifier using neural networks.
